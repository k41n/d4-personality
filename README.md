# Бросок 1d4 — «Личность»

Устанавливаемое PWA: бросок четырёхгранной кости, четыре личности на гранях
развёртки тетраэдра. Работает полностью офлайн — без бэкенда, без CDN, без
сборки и без рантайм-зависимостей.

## Структура

```
index.html              разметка (перенесена из d4-lichnost.html один в один)
styles.css              стили и дизайн-токены
app.js                  логика броска, localStorage, вибро, регистрация SW
manifest.webmanifest    манифест установки
sw.js                   service worker: precache + cache-first
icons/                  192, 512, maskable 512, apple-touch-icon 180
d4-lichnost.html        исходный однофайловый прототип (не используется рантаймом)
```

## Запуск локально

Service worker требует `http(s)` и защищённый контекст, поэтому открывать
`index.html` через `file://` нельзя — нужен любой статический сервер на
`localhost`/`127.0.0.1`:

```sh
python3 -m http.server 8811        # затем http://127.0.0.1:8811/
# или
npx --yes http-server -p 8811 -c-1
```

Питоновский сервер отдаёт `.webmanifest` как `application/octet-stream`; для
работы в браузере этого достаточно, но чтобы Lighthouse видел манифест
корректно, отдавайте его как `application/manifest+json` (см. ниже про хостинг —
GitHub Pages делает это сам).

Проверка офлайна: открыть страницу, дождаться регистрации SW
(DevTools → Application → Service Workers), остановить сервер и перезагрузить
страницу — приложение должно подняться целиком.

## Где живёт

**https://k41n.github.io/d4-personality/** — GitHub Pages, ветка `main`, корень
репозитория. Обновление: `git push` в `main`, Pages пересобирается сам.

Все пути относительные (`./`), `start_url` и `scope` — тоже, поэтому приложение
одинаково работает и в подкаталоге Pages, и в корне любого другого статического
хостинга.

### Обновление версии

`sw.js` кеширует по константе `CACHE_NAME`. После изменения любого статического
файла поднимите версию (`d4-lichnost-v1` → `v2`) — на `activate` старые кеши
удаляются, клиенты получают свежие файлы.

## Поведение

- **Установка:** `display: standalone`, `orientation: portrait`,
  `theme_color`/`background_color` — `#241E23` (цвет стола из палитры).
- **iOS standalone:** `viewport-fit=cover` + `env(safe-area-inset-*)` в паддингах
  body, `apple-mobile-web-app-capable`, статус-бар `black-translucent`,
  `apple-touch-icon` 180×180.
- **Тач:** `touch-action: manipulation` и прозрачный
  `-webkit-tap-highlight-color` убирают double-tap zoom и подсветку тапов;
  масштабирование щипком **не** запрещено (`user-scalable` не трогаем).
- **Вибро:** серия коротких щелчков на время анимации броска и один импульс
  55 мс в момент фиксации грани — только если `navigator.vibrate` поддерживается.
- **Доступность:** строка результата под `aria-live="polite"`, у обеих кнопок
  видимый `:focus-visible` (латунная обводка), `prefers-reduced-motion: reduce`
  выключает анимацию перебора граней и показывает результат сразу.
